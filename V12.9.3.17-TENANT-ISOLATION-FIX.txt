Tabaja Solution V12.9.3.17 — Tenant Isolation Fix

Fixed:
- Cloud customer login now sets the authenticated company as the active workspace before the UI opens.
- Cloud signup now sets the newly created company as the active workspace.
- Tenant storage keys now prioritize immutable companyId, isolating multiple users of the same company.
- Cloud workspace load now includes trial and feature flags (NFC / Batch).
- Employee Manager reloads its in-memory data immediately on company/account switch.
- Logout clears the active/fallback workspace so the next login cannot inherit the previous company.
- Cache/version bumped to V12.9.3.17 so GitHub/PWA clients receive the corrected files.

Safety:
- Existing per-company local data is not deleted.
- Admin legacy template fallback remains Admin-only.
